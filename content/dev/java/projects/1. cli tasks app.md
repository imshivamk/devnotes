This is a complete, well-documented project structure. I have separated the concerns into **Model** (Data shape), **DAO** (Database logic), and **Servlet** (HTTP logic). This is the standard "Java way" to organize backend code.

### 1. Database Schema (SQL)

Run this in your PostgreSQL tool (pgAdmin or terminal) to set up the table.

```sql
-- Create the database (optional, if you haven't already)
CREATE DATABASE notes_db;

-- Connect to the database and run:
CREATE TABLE notes (
    id SERIAL PRIMARY KEY,              -- Auto-incrementing Integer ID
    user_id VARCHAR(50) NOT NULL,       -- Storing the User ID (from your frontend/auth)
    title VARCHAR(100) NOT NULL,
    content TEXT NOT NULL,
    is_pinned BOOLEAN DEFAULT FALSE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Optional: Index for faster lookups by user
CREATE INDEX idx_notes_user ON notes(user_id);

```

### 3. The Model (`src/main/java/com/example/model/Note.java`)

This is the **POJO** (Plain Old Java Object). It represents a single row in your database table.

```java
package com.example.model;

public class Note {
    private int id;
    private String userId;
    private String title;
    private String content;
    private boolean isPinned;
    // We can ignore created_at for now to keep it simple

    // Empty constructor (Required for Gson to build the object)
    public Note() {}

    // Full constructor (Useful for manual creation)
    public Note(String userId, String title, String content, boolean isPinned) {
        this.userId = userId;
        this.title = title;
        this.content = content;
        this.isPinned = isPinned;
    }

    // Getters and Setters (Boilerplate needed for Java to access private fields)
    public int getId() { return id; }
    public void setId(int id) { this.id = id; }

    public String getUserId() { return userId; }
    public void setUserId(String userId) { this.userId = userId; }

    public String getTitle() { return title; }
    public void setTitle(String title) { this.title = title; }

    public String getContent() { return content; }
    public void setContent(String content) { this.content = content; }

    public boolean isPinned() { return isPinned; }
    public void setPinned(boolean pinned) { isPinned = pinned; }
}

```

### 4. The Data Access Object (`src/main/java/com/example/dao/NoteDAO.java`)

This file handles **only** database interactions. It isolates SQL from your HTTP logic. It is equivalent to the Mongoose methods (`.find()`, `.save()`).

```java
package com.example.dao;

import com.example.model.Note;
import java.sql.*;
import java.util.ArrayList;
import java.util.List;

public class NoteDAO {

    // DB Connection Properties
    private final String URL = "jdbc:postgresql://localhost:5432/notes_db";
    private final String USER = "postgres"; 
    private final String PASS = "password"; // CHANGE THIS

    // Helper method to get a connection
    private Connection getConnection() throws SQLException {
        try {
            // Load driver manually (sometimes needed in older environments)
            Class.forName("org.postgresql.Driver");
            return DriverManager.getConnection(URL, USER, PASS);
        } catch (ClassNotFoundException e) {
            throw new SQLException("Postgres Driver not found", e);
        }
    }

    // CREATE
    public Note createNote(Note note) throws SQLException {
        String sql = "INSERT INTO notes (user_id, title, content, is_pinned) VALUES (?, ?, ?, ?) RETURNING id";
        
        try (Connection conn = getConnection();
             PreparedStatement stmt = conn.prepareStatement(sql)) {
             
            stmt.setString(1, note.getUserId());
            stmt.setString(2, note.getTitle());
            stmt.setString(3, note.getContent());
            stmt.setBoolean(4, note.isPinned());

            // Execute and get the generated ID back
            ResultSet rs = stmt.executeQuery();
            if (rs.next()) {
                note.setId(rs.getInt("id"));
            }
            return note;
        }
    }

    // READ (All for User)
    public List<Note> getNotesByUserId(String userId) throws SQLException {
        List<Note> notes = new ArrayList<>();
        String sql = "SELECT * FROM notes WHERE user_id = ? ORDER BY created_at DESC";

        try (Connection conn = getConnection();
             PreparedStatement stmt = conn.prepareStatement(sql)) {
            
            stmt.setString(1, userId);
            ResultSet rs = stmt.executeQuery();

            while (rs.next()) {
                Note n = new Note();
                n.setId(rs.getInt("id"));
                n.setUserId(rs.getString("user_id"));
                n.setTitle(rs.getString("title"));
                n.setContent(rs.getString("content"));
                n.setPinned(rs.getBoolean("is_pinned"));
                notes.add(n);
            }
        }
        return notes;
    }

    // READ (Single by ID)
    public Note getNoteById(int noteId) throws SQLException {
        String sql = "SELECT * FROM notes WHERE id = ?";
        
        try (Connection conn = getConnection();
             PreparedStatement stmt = conn.prepareStatement(sql)) {
            
            stmt.setInt(1, noteId);
            ResultSet rs = stmt.executeQuery();

            if (rs.next()) {
                Note n = new Note();
                n.setId(rs.getInt("id"));
                n.setUserId(rs.getString("user_id"));
                n.setTitle(rs.getString("title"));
                n.setContent(rs.getString("content"));
                n.setPinned(rs.getBoolean("is_pinned"));
                return n;
            }
        }
        return null; // Return null if not found
    }

    // UPDATE
    public boolean updateNote(Note note) throws SQLException {
        String sql = "UPDATE notes SET title = ?, content = ?, is_pinned = ? WHERE id = ? AND user_id = ?";
        
        try (Connection conn = getConnection();
             PreparedStatement stmt = conn.prepareStatement(sql)) {
            
            stmt.setString(1, note.getTitle());
            stmt.setString(2, note.getContent());
            stmt.setBoolean(3, note.isPinned());
            stmt.setInt(4, note.getId());
            stmt.setString(5, note.getUserId()); // Security check: Ensure user owns note

            int rowsUpdated = stmt.executeUpdate();
            return rowsUpdated > 0;
        }
    }

    // DELETE
    public boolean deleteNote(int id, String userId) throws SQLException {
        String sql = "DELETE FROM notes WHERE id = ? AND user_id = ?";
        
        try (Connection conn = getConnection();
             PreparedStatement stmt = conn.prepareStatement(sql)) {
            
            stmt.setInt(1, id);
            stmt.setString(2, userId);

            int rowsDeleted = stmt.executeUpdate();
            return rowsDeleted > 0;
        }
    }
}
```

### 5. The Controller (`src/main/java/com/example/servlet/NoteServlet.java`)

This is the equivalent of your `app.get`, `app.post` in Express.

```java
package com.example.servlet;

import com.example.dao.NoteDAO;
import com.example.model.Note;
import com.google.gson.Gson;
import com.google.gson.JsonObject;

import javax.servlet.ServletException;
import javax.servlet.annotation.WebServlet;
import javax.servlet.http.*;
import java.io.BufferedReader;
import java.io.IOException;
import java.sql.SQLException;
import java.util.List;

// Map this servlet to /api/notes/*
@WebServlet("/api/notes/*")
public class NoteServlet extends HttpServlet {

    private NoteDAO noteDAO;
    private Gson gson;

    // Initialize resources (runs once when server starts)
    @Override
    public void init() {
        noteDAO = new NoteDAO();
        gson = new Gson();
    }

    // ---------------------------------------------------------
    // HELPER METHODS
    // ---------------------------------------------------------

    // Send JSON Response (res.json)
    private void sendJson(HttpServletResponse resp, int status, Object data) throws IOException {
        resp.setStatus(status);
        resp.setContentType("application/json");
        resp.setCharacterEncoding("UTF-8");
        resp.getWriter().write(gson.toJson(data));
    }

    // Parse ID from URL (e.g., /api/notes/5 -> returns 5)
    private Integer getPathId(HttpServletRequest req) {
        String pathInfo = req.getPathInfo();
        if (pathInfo == null || pathInfo.equals("/")) return null;
        try {
            // substring(1) removes the leading slash
            return Integer.parseInt(pathInfo.substring(1));
        } catch (NumberFormatException e) {
            return null;
        }
    }

    // Get User ID from Header (Simulating Middleware)
    private String getUserId(HttpServletRequest req) {
        return req.getHeader("userId");
    }

    // ---------------------------------------------------------
    // HTTP METHODS
    // ---------------------------------------------------------

    // CREATE (POST)
    @Override
    protected void doPost(HttpServletRequest req, HttpServletResponse resp) throws IOException {
        try {
            String userId = getUserId(req);
            if (userId == null) {
                sendJson(resp, 400, new ResponseMsg("User Id is required!"));
                return;
            }

            // Parse Request Body
            BufferedReader reader = req.getReader();
            Note newNote = gson.fromJson(reader, Note.class);

            if (newNote.getTitle() == null || newNote.getContent() == null) {
                sendJson(resp, 400, new ResponseMsg("Title and Content are required"));
                return;
            }

            newNote.setUserId(userId);
            Note savedNote = noteDAO.createNote(newNote);

            sendJson(resp, 201, new ResponseMsg("Note created", savedNote));

        } catch (Exception e) {
            e.printStackTrace();
            sendJson(resp, 500, new ResponseMsg("Internal Server Error", e.getMessage()));
        }
    }

    // READ (GET)
    @Override
    protected void doGet(HttpServletRequest req, HttpServletResponse resp) throws IOException {
        try {
            String userId = getUserId(req);
            if (userId == null) {
                sendJson(resp, 400, new ResponseMsg("User Id is required!"));
                return;
            }

            Integer noteId = getPathId(req);

            // Get All Notes
            if (noteId == null) {
                List<Note> notes = noteDAO.getNotesByUserId(userId);
                JsonObject response = new JsonObject();
                response.addProperty("success", true);
                response.add("notes", gson.toJsonTree(notes));
                sendJson(resp, 200, response);
            } 
            // Get Single Note
            else {
                Note note = noteDAO.getNoteById(noteId);
                
                if (note == null) {
                    sendJson(resp, 404, new ResponseMsg("Note not found"));
                    return;
                }
                
                // Auth Check
                if (!note.getUserId().equals(userId)) {
                    sendJson(resp, 403, new ResponseMsg("Unauthorized access"));
                    return;
                }

                sendJson(resp, 200, note);
            }
        } catch (Exception e) {
            e.printStackTrace();
            sendJson(resp, 500, new ResponseMsg("Internal Error", e.getMessage()));
        }
    }

    // UPDATE (PUT)
    @Override
    protected void doPut(HttpServletRequest req, HttpServletResponse resp) throws IOException {
        try {
            Integer noteId = getPathId(req);
            String userId = getUserId(req);

            if (noteId == null || userId == null) {
                sendJson(resp, 400, new ResponseMsg("Note ID and User ID required"));
                return;
            }

            Note reqBody = gson.fromJson(req.getReader(), Note.class);
            reqBody.setId(noteId);
            reqBody.setUserId(userId);

            boolean updated = noteDAO.updateNote(reqBody);

            if (updated) {
                sendJson(resp, 200, new ResponseMsg("Note updated successfully"));
            } else {
                sendJson(resp, 404, new ResponseMsg("Note not found or Unauthorized"));
            }

        } catch (Exception e) {
            e.printStackTrace();
            sendJson(resp, 500, new ResponseMsg("Internal Error", e.getMessage()));
        }
    }

    // DELETE (DELETE)
    @Override
    protected void doDelete(HttpServletRequest req, HttpServletResponse resp) throws IOException {
        try {
            Integer noteId = getPathId(req);
            String userId = getUserId(req);

            if (noteId == null || userId == null) {
                sendJson(resp, 400, new ResponseMsg("Note ID and User ID required"));
                return;
            }

            boolean deleted = noteDAO.deleteNote(noteId, userId);

            if (deleted) {
                sendJson(resp, 200, new ResponseMsg("Note deleted successfully"));
            } else {
                sendJson(resp, 404, new ResponseMsg("Note not found or Unauthorized"));
            }

        } catch (Exception e) {
            e.printStackTrace();
            sendJson(resp, 500, new ResponseMsg("Internal Error", e.getMessage()));
        }
    }

    // Simple Class for consistent JSON responses
    static class ResponseMsg {
        String message;
        Object data; // Can hold a Note object, or error details

        ResponseMsg(String message) { this.message = message; }
        ResponseMsg(String message, Object data) { 
            this.message = message; 
            this.data = data; 
        }
    }
}
```

### How to Run

1. Open **IntelliJ IDEA**.
2. Open the `pom.xml` file as a project.
3. Ensure your PostgreSQL database is running and credentials in `NoteDAO.java` are correct.
4. In the Maven sidebar, run: `Plugins` -> `tomcat7` -> `tomcat7:run`.
5. Your API is live at `http://localhost:8080/api/notes`.
