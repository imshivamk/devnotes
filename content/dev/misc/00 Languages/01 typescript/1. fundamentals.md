### Basic Types & Annotations

In TypeScript, we use **Type Annotations** to explicitly tell the compiler what data type a variable should hold. The syntax is strictly `variable: type`.

Here are the three most common primitives:

- `string`: Text values (e.g., `"Hello"`)
    
- `number`: Integers and floats (e.g., `42`, `3.14`)
    
- `boolean`: True or false values (e.g., `true`, `false`)
    

```ts
let username: string = "Alice";

username = "Bob"; //works
username = 44; //wrong
```

- **`unknown`**: The "safe" wildcard. Like `any`, you can assign anything to it. _However_, TypeScript won't let you use the variable until you verify what it actually is (we'll cover how to verify later).
    
- **`void`**: Usually seen in functions to say "this returns nothing."
    
- **`never`**: Represents a value that never occurs (e.g., a function that throws an error and never finishes).Use this when a function _cannot_ finish running normally. This happens if the function throws an error or has an infinite loop.

```ts
function logMessage(msg: string) : void {
	console.log(msg);
}

function throwError(msg: string) : never {
	throw new Error(msg);
}

const logError(msg:string) : void => {
}
```

### Type Inference

You don't always need to write the type explicitly. If you initialize a variable immediately, TypeScript allows you to skip the annotation because it can "infer" (guess) the type based on the value.

TypeScript

```ts
let age = 25; // TypeScript knows 'age' is a number
age = "Too old"; // ❌ Error: Type 'string' is not assignable to type 'number'
```

_Note: It is generally best practice to rely on inference for simple variables to keep code clean._


### Arrays & Tuples

#### 1. Arrays

There are two ways to define an array (a list of items of the same type):

1. `type[]` (Most common)
2. `Array<type>` (Generic syntax)

TypeScript

```ts
let skills: string[] = ["JS", "TS", "React"];
// OR
let scores: Array<number> = [10, 20, 30];
```

#### 2. Tuples

Tuples are special arrays with a **fixed number of elements** and **specific types** at specific positions. They are great for simple data structures like coordinates or key-value pairs.

TypeScript

```ts
// A user record with [Name, ID, IsActive]
let userRecord: [string, number, boolean] = ["Alice", 101, true];

userRecord[0] = 500; // ❌ Error: Index 0 must be a string
```
