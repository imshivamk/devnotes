Authentication and Authorization are critical to secure your backend APIs:

>**Authentication:** Who are you? (logging in users and verifying identity)


- It's the process of verifying the identity of users accessing a backend system.
- It ensures that only authorized users can access protected resources and functionality.
- In backend development, this is commonly handled through mechanisms such as sessions or, increasingly, **token-based authentication**. 

- One of the most popular token standards for web APIs is [[3. JWT(JSON web tokens)]]

## 2. Update Model for password hashing

const mongoose = require('mongoose');

```js
const userSchema = new mongoose.Schema({
name:{
	type:String,

	trim:true

	type:String,
	required:true,
	unique:true,
	lowercase:true

	type:String,

	type:String,
	enum: ['user', 'admin'],
	default:'user'
},

	type:Date,
	default: Date.now
}

```

>Hash the password before saving user

```js
userSchema.pre('save', async function (next){
	if(!this.isModified('password')) return next();
	const salt = await bcrypt.genSalt(10);
	this.password = await bcrypt.hash(this.password, salt);
	next();
});
```


> instance method to compare password

```js
userSchema.methods.matchPassword = function(enteredPassword){
	return bcrypt.compare(enteredPassword, this.password);
};
```

```js
const User = mongoose.model('User', userSchema);
module.exports = User;
```

## 3. Generate JWT Token Utility

```js
const jwt = require('jsonwebtoken');

const generateToken = (user) =>{
	return jwt.sign(
	{
		id: user._id,
		role: user.role
	},
	process.env.JWT_KEY,
	{
		expiresIn: "1h"
	}
  );
}

module.exports = generateToken;
```

		// create user password hashing handled in the model
		const user = await User.create({name, email, password});
		res.status(201).json({
			id : user._id,
			name: user.name,
			email: user.email,
			role:user.role,
