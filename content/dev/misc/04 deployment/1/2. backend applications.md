## 2. VMs

### EC2

1. create an EC2 instance
2. push source code to github
3. connect to EC2 instace
4. install nodejs using nvm (refer digital ocean post)
5.  clone the github repo
6. `npm install` and `npm run dev`
7. `npm run build` and `npm start`
8. go to EC2 instance's security group tab, add an inbound rule to allow custom TCP traffic from anywhere on a port 
9. `ec2-Ip:3000`
10. go to domain provider, go to dns and manage custom records
11. new record, A record, points to IP of instance
12. serve it on port 80 using npm serve, reverse proxy(nginx) + certbot
