## 2. VM (e.g AWS EC2)
In a react app, we run `npm run build`, which creates a `dist` folder, which has the `index.html` with styles and javacript

1. get a VM
2. install nodejs `sudo install nodejs`
3. copy source code in VM
4. start application in prod/dev
5. `npm run build`
6. `cd /dist`
7. `sudo npm i -g serve` and `serve`
8. `sudo serve -p 80` port 80

### using AWS : 

1. create EC2 instance
2. select Os - linux (ubuntu)
3. key-pair for connecting to a vm
4. network settings - setup firewall
5. Launch instance
6. install `serve` as SU in VM then serve /dist static files.
7. `certbot`

## 3. CDNs and Object stores
1. CDN - cloudfront (AWS), cloudfare, Bunny 
2. object store - S3(AWS), R2(Cloudfare), Cloudinary

Use case : 
1. serving videos (youtube)
2. serving images (instagram)
3. static websites

**Don't use with server side rendering**

Steps : 

1. create object store
	1. create a S3 bucket
	2. `npm run build`
	3. upload `/dist` to S3
2. create CDN
	1. create CDN
	2. setup domain
	3. to add custom domain : add custom hostname
	4. go to domain provider like google domains or godaddy, add CNAME and url
3. connect the CDN to the object store
4. connect domain to the CDN
