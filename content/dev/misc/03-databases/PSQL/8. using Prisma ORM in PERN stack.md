
# Prisma

Prisma is a modern, next-generation ORM for Node.js and TypeScript that provides:

- Type-safe database access based on a schema definition.
- A declarative Prisma schema approach instead of model classes.
- Autogenerated query client with an intuitive API.
- Support for PostgreSQL and many other databases.

It balances ease of use with powerful control over your database.

***

## Setup Prisma in a PERN project

### 1. Initialize Node.js project

```bash
mkdir pern-prisma-app
cd pern-prisma-app
npm init -y
```


### 2. Install required dependencies

```bash
npm install express @prisma/client
npm install --save-dev prisma dotenv
```


### 3. Initialize Prisma client and schema

```bash
npx prisma init
```

This creates:

- `prisma/schema.prisma` — your data model schema
- `.env` — environment variables file

***

## Configure PostgreSQL database in `.env`

Edit `.env` and add your Postgres connection string:

```env
DATABASE_URL="postgresql://user:password@localhost:5432/yourdb?schema=public"
```


***

## Define data models in `prisma/schema.prisma`

Example User and Post models:

```prisma
datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}

generator client {
  provider = "prisma-client-js"
}

model User {
  id    Int     @id @default(autoincrement())
  email String  @unique
  name  String?
  posts Post[]
}

model Post {
  id        Int    @id @default(autoincrement())
  title     String
  content   String?
  published Boolean @default(false)
  authorId  Int
  author    User   @relation(fields: [authorId], references: [id])
}
```


***

## Generate Prisma Client

After editing schema, generate client with:

```bash
npx prisma generate
```


***

## Run migrations (create tables in database)

```bash
npx prisma migrate dev --name init
```

## Using Prisma Client in Express (ES6 modules)

Create `src/db.js` to instantiate PrismaClient:

```javascript
import { PrismaClient } from '@prisma/client';

const prisma = new PrismaClient();

export default prisma;
```


***

### Example Express server `src/index.js`:

```javascript
import express from 'express';
import dotenv from 'dotenv';
import prisma from './db.js';

dotenv.config();

const app = express();
app.use(express.json());

const PORT = process.env.PORT || 5000;

// Example route to get all users with posts
app.get('/api/users', async (req, res) => {
  try {
    const users = await prisma.user.findMany({
      include: { posts: true },
    });
    res.json(users);
  } catch (error) {
    res.status(500).json({ error: 'Failed to fetch users' });
  }
});

// Graceful shutdown - disconnect Prisma
process.on('SIGINT', async () => {
  await prisma.$disconnect();
  process.exit(0);
});

app.listen(PORT, () => console.log(`Server started on port ${PORT}`));
```

## Using Prisma Client in CRUD operations

**Create a new user:**

```javascript
const newUser = await prisma.user.create({
  data: {
    email: 'test@example.com',
    name: 'John Doe',
    posts: {
      create: [{ title: 'My first post' }],
    },
  },
});
```

**Fetch a specific post by ID:**

```javascript
const post = await prisma.post.findUnique({
  where: { id: 1 },
  include: { author: true },
});
```

**Update a user:**

```javascript
const updatedUser = await prisma.user.update({
  where: { id: 1 },
  data: { name: 'Jane Doe' },
});
```

**Delete a post:**

```javascript
const deletedPost = await prisma.post.delete({
  where: { id: 1 },
});
```

## Recommended development workflows

- Use `.env` for all secrets, not hardcoding credentials.
- Use Prisma migrations (`prisma migrate`) to evolve schema safely.
- Use Prisma Client for all DB queries, avoiding raw SQL when possible.
- Handle errors with try/catch and respond with appropriate HTTP statuses.
- Disconnect Prisma client gracefully on app termination.
- TypeScript users get type safety with generated Prisma Client.
- Integrate Prisma in services or controllers for cleaner code organization.
