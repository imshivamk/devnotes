## A. Java/Spring Boot + PostgreSQL

### 1. Add PostgreSQL JDBC Driver
-  Maven
```xml
<dependency>
  <groupId>org.postgresql</groupId>
  <artifactId>postgresql</artifactId>
  <version>42.7.1</version>
</dependency>
```

### 2. Configure Database Settings

- in `src/main/resources/application.properties` :
```
spring.datasource.url=jdbc:postgresql://localhost:5432/mydb
spring.datasource.username=yourusername
spring.datasource.password=yourpassword
spring.datasource.driver-class-name=org.postgresql.Driver
```


### 3. Use JDBC or JPA for Access

- JDBC template (raw SQL)
```java
@Autowired
JdbcTemplate jdbcTemplate;

public List<User> getAllUsers() {
    return jdbcTemplate.query(
        "SELECT * FROM users",
        (rs, rowNum) -> new User(rs.getInt("id"), rs.getString("username"))
    );
}
```

- JPA (ORM, most use cases)
```java
@Entity
public class User {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private int id;
    private String username;
    // getters/setters...
}

public interface UserRepository extends JpaRepository<User, Integer> {}
```

 Now you can inject (`@Autowired`) `UserRepository` and use CRUD methods directly: `findAll()`, `save()`, etc.

### 4. Transactions & Error Handling
- Use `@Transactional` on service methods for ACID-compliance.
- Catch and handle exceptions as appropriate.
### 5. Database Migrations
- Use Flyway or Liquibase to automate schema changes.

## B. Java / Spring Boot / PostgreSQL project

- project structures
```
- src/
  - main/
    - java/
      - com.example.notes/
        - controller/
        - model/
        - repository/
        - service/
    - resources/
      - application.properties
```

- **Model (`Note.java`)**: describes your “Note” with fields and mapping annotations.
- **Repository (`NoteRepository.java`)**: instantly gives you database CRUD, query methods.
- **Service (`NoteService.java`)**: (optional) holds reusable business logic.
- **Controller (`NoteController.java`)**: defines REST API endpoints for your app.
- **application.properties**: configures the whole app’s backend to hit your DB.
- **Annotations**: tell Spring exactly what roles your classes play and how they connect.

## Step 1: application.properties (DB Config)

```
spring.datasource.url=jdbc:postgresql://localhost:5432/notesdb
spring.datasource.username=youruser
spring.datasource.password=yourpassword
spring.datasource.driver-class-name=org.postgresql.Driver
spring.jpa.hibernate.ddl-auto=update
```

## Step 2: Model

 `src/main/java/com/example/notes/model/Note.java`

```java
@Entity
public class Note{
	@Id
	@GeneratedValue(strategy = GenerationType.IDENTITY)
	private long id;

	@Column(nullable = false)
	private String title;

	@Column(nullable = false)
	private String content;

	
}
```

## Step 3: Repository

`src/main/java/com/example/notes/repository/NoteRepository.java`

```java
@Repository
public interface NoteRepository extends JppaRepository
<Note, Long> {}
```
