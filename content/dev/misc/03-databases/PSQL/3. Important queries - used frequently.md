## 1. `CURRENT_DATE()` & `CURRENT_TIME`

- Returns today’s date or current time.
- Useful for timestamps.

```sql
SELECT CURRENT_DATE, CURRENT_TIME;
```

## 2. `CHECK`

- Adds a custom rule

```sql
CREATE TABLE products (
	price NUMERIC CHECK (price > 0) 
);
```

## 3. FUNCTIONS (SQL Built-in Functions)

- Examples: `UPPER(text)`, `ROUND(number)`, `NOW()`

```sql
SELECT UPPER(username), ROUND(amount), NOW() FROM orders;
```


## 4. `AND`, `OR`, `NOT` (Logical Operators)

- Used to combine conditions in WHERE clauses.
```sql
SELECT * FROM users WHERE active = true AND last_login > CURRENT_DATE - INTERVAL '30 days';
```

## 5. WILDCARDS (`LIKE`, `%`, `_`)

- Used in text searching.

```sql
SELECT * FROM users WHERE username LIKE 'a%';

SELECT * FROM users WHERE email LIKE '%@gmail.com';
```
 
`..%` -  Starts with 'a'
`%..` - Ends with @gmail.com`

## 6. `ORDER BY`

- Sorts your results.
```sql
SELECT * FROM orders ORDER BY amount DESC, created_at ASC;
```

## 7. `LIMIT`

- Restricts result count.

```sql
SELECT * FROM orders LIMIT 5;`
```
## 8. `UNION`

- Combines results from multiple SELECTs; duplicates removed (use `UNION ALL` for duplicates).

```sql
SELECT username FROM users UNION SELECT buyer_name FROM orders;`
```

## 9. SELF JOINS

- A table joined to itself—useful for things like organizational charts or hierarchies.

```sql
SELECT a.username, b.username AS manager
FROM users a
JOIN users b ON a.manager_id = b.id;
```



## 10. `ROLLUP`

- Adds subtotals and grand total rows when grouping.

```sql
SELECT department, SUM(salary)
FROM employees
GROUP BY ROLLUP(department);
```
## 11. `ON DELETE`

- Alters what happens to FK rows if the referenced row is deleted (e.g., `CASCADE`, `SET NULL`).

```sql
CREATE TABLE orders (
  user_id INTEGER REFERENCES users(id) ON DELETE SET NULL
);
```

## 12. STORED PROCEDURES

- SQL routines stored in the database, called with parameters to run reusable logic. Like methods or functions in programming languages.

```sql
-- Example in PostgreSQL
CREATE OR REPLACE PROCEDURE update_stock(pid INT, change INT)
LANGUAGE plpgsql AS $$
BEGIN
  UPDATE products SET stock = stock + change WHERE id = pid;
END; $$;
CALL update_stock(1, 5);

```

## 13. TRIGGERS

- Automatically run code (like a function) when something happens (insert/update/delete).

```sql
-- Example: Log every new order
CREATE OR REPLACE FUNCTION log_order() RETURNS trigger AS $$
BEGIN
  INSERT INTO order_log(order_id, created_at) VALUES (NEW.id, NOW());
  RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER order_created
AFTER INSERT ON orders
FOR EACH ROW EXECUTE FUNCTION log_order();

```
