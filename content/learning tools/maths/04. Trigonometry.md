
### 1. Simple Trigonometric Identities

Identities are equations involving trigonometric functions that are true for every value of the variables involved.

![](04.%20Trigonometry-1772184161587.webp)

#### **Core Concepts & Formulas**

- **Reciprocal Identities**:
    
    - $\sin \theta = \frac{1}{\csc \theta}$
        
    - $\cos \theta = \frac{1}{\sec \theta}$
        
    - $\tan \theta = \frac{1}{\cot \theta} = \frac{\sin \theta}{\cos \theta}$
        
- **Pythagorean Identities**:
    
    - $\sin^{2} \theta + \cos^{2} \theta = 1$
        
    - $1 + \tan^{2} \theta = \sec^{2} \theta$
        
    - $1 + \cot^{2} \theta = \csc^{2} \theta$
        
- **Addition and Subtraction Formulas**:
    
    - $\sin(A \pm B) = \sin A \cos B \pm \cos A \sin B$
        
    - $\cos(A \pm B) = \cos A \cos B \mp \sin A \sin B$
        
- **Multiple Angle Formulas**:
    
    - $\sin 2\theta = 2\sin\theta\cos\theta$
        
    - $\cos 2\theta = \cos^{2}\theta - \sin^{2}\theta = 2\cos^{2}\theta - 1 = 1 - 2\sin^{2}\theta$
        

> **Solved Example**: If $\sin \theta = 3/5$ and $\theta$ is in the first quadrant, find $\cos \theta$ and $\tan \theta$.
> 
> **Step 1**: Use the identity $\sin^{2} \theta + \cos^{2} \theta = 1$.
> 
> **Step 2**: $(3/5)^{2} + \cos^{2} \theta = 1 \Rightarrow 9/25 + \cos^{2} \theta = 1 \Rightarrow \cos^{2} \theta = 16/25$.
> 
> **Step 3**: Since it is the first quadrant, $\cos \theta = 4/5$.
> 
> **Solution**: $\cos \theta = 4/5$, $\tan \theta = \frac{3/5}{4/5} = 3/4$.

### 2. Trigonometric Equations

These are equations that contain one or more trigonometric functions of variable angles.

#### **Core Concepts & General Solutions**

- If $\sin \theta = \sin \alpha$, then **$\theta = n\pi + (-1)^{n}\alpha$**.
    
- If $\cos \theta = \cos \alpha$, then **$\theta = 2n\pi \pm \alpha$**.
    
- If $\tan \theta = \tan \alpha$, then **$\theta = n\pi + \alpha$**.
    
    _(Where $n$ is any integer)._
    

> **Solved Example**: Solve for $\theta$: $2\sin\theta - 1 = 0$.
> 
> **Step 1**: $\sin\theta = 1/2$.
> 
> **Step 2**: We know $\sin(\pi/6) = 1/2$. So, $\alpha = \pi/6$.
> 
> **Step 3**: General solution is $\theta = n\pi + (-1)^{n}(\pi/6)$.
> 
> **Solution**: $\theta = n\pi + (-1)^{n}\frac{\pi}{6}, n \in \mathbb{Z}$.

### 3. Properties of Triangles & Solution of Triangles

This involves using sine and cosine rules to find unknown sides or angles of a triangle.

#### **Core Concepts & Formulas**

- **Sine Rule**: $\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$ (where $R$ is the circumradius).
    
- **Cosine Rule**:
    
    - $a^{2} = b^{2} + c^{2} - 2bc \cos A$
        
    - $\cos A = \frac{b^{2} + c^{2} - a^{2}}{2bc}$
        
- **Projection Rule**: $a = b \cos C + c \cos B$.
    
- **Area of Triangle**: $\Delta = \frac{1}{2}bc \sin A$.
    

> **Solved Example**: In a triangle, if $b = 3, c = 5,$ and $\angle A = 60^{\circ}$, find side $a$.
> 
> **Step 1**: Use Cosine Rule: $a^{2} = 3^{2} + 5^{2} - 2(3)(5)\cos 60^{\circ}$.
> 
> **Step 2**: $a^{2} = 9 + 25 - 30(1/2) = 34 - 15 = 19$.
> 
> **Solution**: $a = \sqrt{19}$.

### 4. Height and Distance

Practical applications using angles of elevation and depression.

#### **Core Concepts**

- **Angle of Elevation**: The angle between the horizontal line and the line of sight when looking **up** at an object.
    
- **Angle of Depression**: The angle between the horizontal line and the line of sight when looking **down** at an object.
    

> **Solved Example**: A tower stands vertically on the ground. From a point 30m away from the foot of the tower, the angle of elevation of the top is $45^{\circ}$. Find the height of the tower.
> 
> **Step 1**: Let $h$ be the height. $\tan 45^{\circ} = \frac{\text{Opposite}}{\text{Adjacent}} = \frac{h}{30}$.
> 
> **Step 2**: Since $\tan 45^{\circ} = 1$, then $1 = h/30$.
> 
> **Solution**: $h = 30$ meters.

### 5. Inverse Trigonometric Functions

Finding the angle when the trigonometric value is known.

#### **Core Concepts & Formulas**

- **Domain & Range**:
    
    - $\sin^{-1}x$: Domain $[-1, 1]$, Range $[-\pi/2, \pi/2]$.
        
    - $\cos^{-1}x$: Domain $[-1, 1]$, Range $[0, \pi]$.
        
- **Identities**:
    
    - $\sin^{-1}x + \cos^{-1}x = \pi/2$
        
    - $\tan^{-1}x + \tan^{-1}y = \tan^{-1}\left(\frac{x+y}{1-xy}\right)$
        

> **Solved Example**: Evaluate $\tan^{-1}(1) + \cos^{-1}(1/2)$.
> 
> **Step 1**: $\tan^{-1}(1) = \pi/4$.
> 
> **Step 2**: $\cos^{-1}(1/2) = \pi/3$.
> 
> **Step 3**: Sum $= \pi/4 + \pi/3 = \frac{3\pi + 4\pi}{12}$.
> 
> **Solution**: $7\pi/12$.
